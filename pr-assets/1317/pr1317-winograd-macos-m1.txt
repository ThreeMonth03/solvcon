The float64 16384 x 16384 x 16384 case was not reportable on this 8 GB
system. Its expected working set is approximately 7.4 GB. The first isolated
round did not complete its first measured call after nine minutes; resident
data had fallen below 1.2 GB while memory compression and page activity kept
increasing. The process was terminated, and no float64 timing is reported.

A preliminary float32 run kept all four rounds in one process. Its first two
rounds were near the accepted range, but later calls slowed sharply as the
working set remained resident. It was rejected before the isolated-process
method was adopted:
